Common questions.

Clear answers about the system price, custom work, upgrades, and management.

Is the $199 USD system a fully custom build?

No. The $199 USD price is for an existing system already built and shown on this website. If you want changes to its screens, workflow, features, automation, or other parts, those changes are priced separately.

Is hosting and ongoing technical management included in the $199 USD price?

No ongoing RSF management fee is included in that base price. You can manage the finished system yourself, or ask RSF to handle hosting and technical care under a separate price agreement.

How is a custom system priced?

We first review the work required. Pricing depends on the system scope, including screens, data, users, permissions, workflow rules, automation, integrations, deployment, and ongoing technical needs. The scope and price are agreed before development begins.

Can an existing system be changed for my business?

Yes. Existing systems can be customized. If RSF manages your system, minor workflow adjustments to the current system are included in managed care. Large changes are priced by agreement.

Can I request improvements later?

Yes. Paid RSF management includes minor workflow adjustments to the current system. Major workflow changes, new modules, major features, large expansions, and significant new integrations are priced by agreement.
