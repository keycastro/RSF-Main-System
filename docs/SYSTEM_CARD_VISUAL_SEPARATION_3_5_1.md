# KEY CASTRO — System Card Visual Separation 3.5.1

## Goal

Make the two published systems immediately read as **separate choices** while preserving the simple 3.5.0 public experience.

## What changed

- Home and Systems cards now share one visual-separation treatment.
- Property Operations Command Center uses a very light warm background, warm border/accent, and readable warm category label.
- Property Inventory Hub uses a very light cool background, cool border/accent, and readable cool category label.
- Both cards use clearer boundaries, a larger gap, soft shadow, and controlled hover/focus treatment.
- Text stays dark and high-contrast. Buttons keep the existing KEY CASTRO navy treatment.
- Mobile cards remain individually bounded when stacked.
- A short helper line tells visitors that each system solves a different problem and to choose one to view.

## What did not change

- business model or pricing
- trusted server-side pricing
- Systems search behavior or metadata
- Contact form or inquiry storage
- private owner Inbox or authentication
- system detail routes
- SEO/canonical URLs/sitemap
- the separation of the two applications
- deployment architecture

## Accessibility

Color is not the only separator. Border, spacing, card shape, typography, focus state, and layout also communicate that each system is an independent choice. Text contrast remains high and reduced-motion behavior is preserved.
